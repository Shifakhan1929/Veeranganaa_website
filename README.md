# Veerangana — Women's Safety Platform 

Veerangana is a women's safety initiative focused on promoting personal security, emergency assistance, and empowerment through technology.

This repository contains the official project website, introducing the application, showcasing its safety features, and sharing information about the team behind it.

##  Website Highlights

- Project introduction and overview.
- Application feature showcase.
- Sakhii virtual assistant introduction.
- About and team section.
- Privacy policy and donation pages.
- Android application download section.

##  Application Features

The website showcases features including:
- SOS emergency alerts.
- Live location sharing.
- Panic mode.
- Audio and video recording.
- Emergency helpline access.
- Sakhii virtual assistant.

*These are features presented by the project website; their availability depends on the mobile application's implementation.*
